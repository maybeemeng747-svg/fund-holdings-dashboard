### B-007: 搭建“海瑞投资审判系统”
- **来源**：投资复盘讨论
- **目标**：把 investment-controller / OpenClaw 从“行情与持仓展示工具”升级为投资决策纠偏系统，重点不是推荐股票，而是持续审查持仓逻辑、证伪条件、仓位纪律和情绪化操作。
- **核心判断**：
  - “海瑞”不是知识库本身，而是一套会调用知识库、财报、现金流、业务数据和估值纪律的审判流程。
  - 不建议把该机制塞进 TradingAgents；TA 更适合做股票研究员，海瑞机制应作为 OpenClaw 主控层下的独立投资审判官模块。
  - 知识库适合作为长期记忆；微信/zcode 或飞书适合作为低摩擦日常对话入口。
- **P0：投资知识库 / 长期记忆**
  - 建立《个人投资宪法》：买入原则、仓位规则、退出规则、估值纪律。
  - 建立股票档案库：买入逻辑、核心假设、验证指标、证伪条件。
  - 建立投资错误案例库：原始判断、实际结果、错误归因、规则修正。
- **P1：海瑞 Agent / 投资审判官**
  - 每日审查：持仓逻辑是否变化、是否有证据证明原判断错误、是否存在情绪化操作、仓位是否超过风险承受范围。
  - 输出动作建议：继续持有、观察、减仓、清仓、禁止加仓，并明确触发条件。
  - 记录每次判断，形成“预测 -> 结果 -> 修正”的投资复盘链路。
- **P2：系统集成**
  - OpenClaw 主控负责调度海瑞 Agent、知识库、行情/持仓数据与外部研究。
  - TradingAgents 提供多空分析和股票研究结论；海瑞 Agent 负责挑战 TA 的依据、风险和失效条件。
  - 微信/zcode 或飞书独立会话作为日常入口，推荐提问方式是：“根据我的投资假设，今天有没有需要改变判断的新证据？”
- **验收标准**：
  - 能为至少一个当前持仓生成完整投资档案。
  - 能按固定模板完成一次盘后审判，并给出证据、风险、纪律检查和行动建议。
  - 能保存审判记录，供后续复盘时追踪当时判断是否正确。
