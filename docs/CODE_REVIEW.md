# 代码审查清单

> 每次代码修改后，按此清单逐项检查。适用于 OpenClaw、Codex CLI、人工审查。

---

## 必查项

### 1. 真实投资数据安全
- [ ] 是否误改了 `portfolio/current_holdings.json`？
- [ ] 是否误改了 `portfolio/transactions.json`？
- [ ] 是否误改了 `portfolio/fund_sector_map.json`？
- [ ] 是否误改了 `portfolio/confirmed_nav_snapshot.json`？
- [ ] 是否把测试数据写入了真实持仓文件？
- [ ] 是否删除了 `portfolio/snapshots/` 中的历史快照？

### 2. JSON 结构完整性
- [ ] 修改后的 JSON 文件能否被 `JSON.parse()` 正常解析？
- [ ] 是否有字段被意外删除或重命名？
- [ ] `updated_at` 时间戳是否正确更新？

### 3. 测试覆盖
- [ ] `npm test` 全部通过？
- [ ] 新增逻辑是否有对应测试？
- [ ] 边界情况是否覆盖（空数据、异常值、缺失字段）？

### 4. 前端展示
- [ ] 修改是否影响看板页面正常渲染？
- [ ] 热力图颜色和数值是否正确？
- [ ] 小屏适配是否仍然正常？

### 5. 代码质量
- [ ] 是否引入了硬编码的行情/净值数据？
- [ ] 是否有未处理的异常或未捕获的 Promise rejection？
- [ ] 是否有 console.log 调试代码残留？

### 6. 可回滚性
- [ ] 修改前是否已 `git commit`？
- [ ] 能否通过 `git revert` 回滚？
- [ ] 是否修改了 Git 已忽略的真实数据文件（应通过导入流程而非直接编辑）？
